Bridging the Gap: Turning Human Know-How into JSON for Smart Manufacturing
📘 Overview

This project converts unstructured industrial product manuals (PDFs) into structured JSON data for smart manufacturing applications. It uses AI to understand and standardize technical specifications written in different formats and styles.

⚙️ How It Works

PDF Upload: User uploads a typed product manual.

Text Extraction: System extracts text and tables using PDF parsing libraries.

Semantic Understanding: AI interprets varied phrases and meanings.

Normalization: Units and terms are standardized.

Output: Data is stored in Excel and converted into JSON format.

🧠 Tech Stack

Frontend: React.js

Backend: Python (FastAPI)

AI/NLP: OpenAI / Hugging Face

Libraries: pdfplumber, PyMuPDF, pandas, openpyxl

🎯 Goal

To bridge human-authored knowledge and machine-readable data, enabling smarter and more automated manufacturing workflows.
